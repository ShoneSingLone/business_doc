# 13. 列宽（column-width）

## 13.1 功能说明

通过 `width` 属性设置列宽度，支持像素值、百分比和自动宽度。

---

## 13.2 不设置宽度

不设置宽度时，列宽度自动适应内容。

---

## 13.3 像素宽度

设置固定像素宽度。

**配置示例**：`width: 120`

---

## 13.4 百分比宽度

设置百分比宽度。

**配置示例**：`width: "20%"`

---

## 13.5 长文本处理

处理超长文本时的宽度设置。

---

## 13.6 API

### width

列宽度配置

| 属性 | 说明 | 类型 |
|------|------|------|
| width | 列宽度（像素或百分比） | Number/String |
| minWidth | 最小宽度 | Number |
| maxWidth | 最大宽度 | Number |
