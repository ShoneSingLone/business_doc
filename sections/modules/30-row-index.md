# 30. 行序号（row-index）

## 30.1 功能说明

通过 `indexOption` 属性配置行序号功能。

---

## 30.2 基础用法

显示行序号。

---

## 30.3 排名模式

从大到小排序并显示排名。

---

## 30.4 API

### indexOption

序号配置

| 属性 | 说明 | 类型 | 默认值 |
|------|------|------|--------|
| type | 序号类型 | String | `index` |
| start | 起始序号 | Number | `1` |
