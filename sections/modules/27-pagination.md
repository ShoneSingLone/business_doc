## 27.4 API

### pagination

分页配置（通常使用独立的分页组件）

| 属性        | 说明     | 类型   | 默认值 |
| ----------- | -------- | ------ | ------ |
| pageSize    | 每页条数 | Number | `10`   |
| currentPage | 当前页码 | Number | `1`    |
| total       | 总条数   | Number | `0`    |
